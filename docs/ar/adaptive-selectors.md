# المحددات التكيفية

تساعد المطابقة التكيفية على العثور على عنصر عند تغير HTML الخاص بالموقع. وهي آلية لترتيب المرشحين بحسب التشابه، وليست ضمانًا دلاليًا بأن العنصر ما زال يمثل الكيان نفسه.

## حفظ عنصر مرجعي

```php
$page = $scraper->get('https://example.com/catalog');
$button = $page->css('button.add-to-cart')->first();

if ($button === null) {
    throw new RuntimeException('Reference button was not found.');
}

$page->remember('catalog.add_to_cart', $button);
$selection = $page->adaptive('catalog.add_to_cart');
```

تُحفظ اللقطة عبر `SnapshotStore`. المخزن الافتراضي في الذاكرة. وللاحتفاظ باللقطات بين عمليات PHP، استخدم `JsonSnapshotStore`:

```php
use HElturkey\WebTrawler\Storage\JsonSnapshotStore;

$store = new JsonSnapshotStore(__DIR__ . '/var/scraper-snapshots.json');
$scraper = Scraper::create(snapshotStore: $store);
```

احمِ ملف اللقطات باعتباره بيانات تطبيق؛ فقد يحتوي على نصوص مستخرجة وروابط وتسميات وسياق بنيوي. لا تضعه في مسار عام.

## المطابقة والنتائج

يستخدم المطابق الافتراضي Profile موزونًا ويقيّم عددًا محدودًا من العناصر المرشحة (الحد الافتراضي الأقصى 5,000). تطبق `match()` افتراضيًا حد ثقة تشابه `0.52`، وهامشًا عن المرشح التالي `0.045`، وحدًا للنتائج مقداره 5 ما لم يغيره المستدعي.

قد تشير النتيجة إلى:

- قبول المطابقة؛
- عدم وجود لقطة؛
- اختلاف المضيف؛
- عدم كفاية سياق اللقطة؛
- عدم وجود مرشح؛
- انخفاض التشابه؛
- غموض بين المرشحين؛
- بلوغ حد المرشحين.

راجع المرشح الأفضل والمرشح التالي عند اتخاذ قرار مهم. انخفاض التشابه أو ضآلة الهامش يجب أن يدفع التطبيق إلى التوقف أو طلب مراجعة بشرية، لا إلى الضغط على عنصر تلقائيًا.

قيمة `confidence` درجة تشابه معيارية، وليست احتمالًا إحصائيًا معايرًا لصحة العنصر.

## ملفات Scoring Profile

يضبط `AdaptiveScoringProfile` أوزانًا محدودة وغير سالبة للإشارات المدعومة. يجب أن تكون الأوزان صالحة وألا تكون جميعها صفرًا. احتفظ بملفات اختبارات مخصصة من تغييرات HTML الفعلية للمواقع المستهدفة.

يستخدم المطابق النص الكامل للمرشح في حساب الدرجة افتراضيًا. أما `maxCandidateTextChars` فهو حد اختياري موجب؛ وقد يؤدي تفعيله إلى تغيير درجات المرشحين ذوي النصوص الطويلة. القيمة الافتراضية `null` تحافظ على سلوك حساب النص الكامل.

## مطابقة المضيف

ترتبط اللقطة بمضيف المصدر. اختلاف المضيف ليس مجرد درجة تشابه منخفضة؛ فلا تعِد استخدام لقطة لمضيف آخر غير مرتبط دون خطة ترحيل صريحة ومراجعة.

## التخزين والتزامن

`InMemorySnapshotStore` محلي للعملية الحالية. أما `JsonSnapshotStore` فيستخدم الأقفال والاستبدال الذري لملف محلي. وهو مناسب لمضيف واحد ونظام ملفات محلي، وليس قاعدة بيانات موزعة أو آلية تنسيق لمجموعة عقد أو Network Filesystem مشترك.

في البيئات متعددة العمال، نفّذ `SnapshotStore` باستخدام قاعدة بيانات أو خدمة تخزين مناسبة للتزامن والتحكم في الوصول.

## إرشادات تشغيلية

- أعد التقاط اللقطات بعد تغييرات التصميم المتعمدة للموقع.
- راقب نتائج القبول والرفض والغموض وافحص حالات القبول الخاطئ.
- احتفظ باختبارات تغيّر للمحددات التي تنفذ دفعًا أو تعديل حساب أو إرسالًا أو حذفًا أو أثرًا جانبيًا آخر.
- فضّل CSS وXPath الصريحين عند توفر محددات مستقرة.
- لا تنفذ عملية حساسة تلقائيًا اعتمادًا على قبول مطابقة تكيفية فقط.
