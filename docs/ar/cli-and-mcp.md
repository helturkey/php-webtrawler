# CLI وخادم MCP

توفر حزمة Composer ملفين تنفيذيين: `scraper` و`scraper-mcp`.

## التثبيت والمساعدة

بعد تثبيت الاعتماديات:

```bash
bin/scraper help
bin/scraper version
bin/scraper fetch --help
bin/scraper crawl --help
```

## أمر fetch

ينفذ `fetch` طلب HTTP واحدًا، ويمكنه إخراج الصفحة أو البيانات المستخرجة. تشمل عناصر التحكم اختيار وسيلة النقل (`guzzle` أو `rnet`)، وملف محاكاة اختياريًا، والمهلة، وعدد/تأخير إعادة المحاولة، وترويسات وبروكسيات متكررة، وحد حجم الجسم، وحظر الشبكات الخاصة، والترميز، والاستخراج باستخدام CSS أو XPath أو خاصية، ومحددات العناصر وحقولها، ووجهة الإخراج وصيغته.

تشمل الصيغ الشائعة JSON وJSONL وCSV وXML والنص. تشمل الخيارات المشتركة `--transport guzzle|rnet` و`--emulation` و`--timeout` و`--retries` و`--retry-delay` و`--proxy` المتكرر و`--header` المتكرر و`--max-bytes` و`--block-private` و`--encoding` و`--format` و`--output`. أما خيارات الاستخراج الخاصة بـ fetch فهي `--select` أو `--xpath` (ولا يجتمعان) و`--attr` و`--html` و`--item` و`--field` المتكرر. صياغة الحقل هي `name=css` أو `name=css@attribute`. يتم اختيار Impity عبر إعداد وسيلة النقل في المكتبة وليس عبر محدد CLI ذي القيمتين `guzzle|rnet`. تعني `--retries N` عدد المحاولات الإضافية بعد المحاولة الأولى.

مثال:

```bash
bin/scraper fetch https://example.com \
  --block-private \
  --max-bytes 10485760 \
  --format json \
  --output page.json
```

لا تفعّل خيار السماح بالشبكات الخاصة في أداة عامة إلا إذا كان المستدعي موثوقًا وكانت الشبكة مقيدة بوسيلة مستقلة.

## أمر crawl

يحمّل أمر الزحف ملف صنف Spider يحدده المستخدم. تشمل الخيارات الشائعة عدد الصفحات والعمق والتزامن والتأخير لكل مضيف وAutoThrottle وملف الحالة. من المفترض الجمع بين حالة الاستئناف وإخراج JSONL وملف Output حتى تُكتب العناصر تدريجيًا بدل الاحتفاظ بها في الذاكرة. يتحقق CLI من مجموعة خيارات الحالة والإخراج المطلوبة.

شكل الأمر (استبدل المسار والصنف بما لديك):

```bash
bin/scraper crawl examples/books-spider.php \
  --class App\\Spiders\\BooksSpider \
  --max-pages 500 \
  --max-depth 8 \
  --concurrency 4 \
  --format jsonl \
  --output books.jsonl \
  --state books.state.json
```

استخدم تزامنًا أكبر من 1 فقط مع وسيلة نقل تدعم Async. يجب أن يكون التزامن 1 مع Rnet وImpity. يتيح `ext-pcntl` التقاط Ctrl-C وSIGTERM وحفظ نقطة الاستعادة.

رموز الخروج:

| الرمز | المعنى |
|---:|---|
| `0` | اكتمل بنجاح |
| `1` | خطأ وقت تشغيل أو زحف |
| `2` | أمر غير صالح أو استخدام خاطئ |
| `130` | إيقاف مبكر مع حفظ الحالة عند إعدادها |

ينقح CLI البيانات الحساسة من بعض رسائل الأخطاء، لكن يجب أن يتعامل كود Spider وMiddleware وPipeline الخاص بالتطبيق مع الأسرار بأمان أيضًا.

## خادم MCP

شغّل خادم stdio:

```bash
bin/scraper-mcp --help
bin/scraper-mcp --allow-host docs.example.com --max-chars 20000
```

ينفذ الخادم JSON-RPC كسطور منفصلة عبر stdin/stdout، ويوفر الأداتين `fetch_page` و`extract`. تشمل خيارات سطر الأوامر `--allow-host HOST` المتكرر و`--max-chars N` و`--transport guzzle|rnet` و`--emulation NAME` وخيار الاستثناء عالي الخطورة `--allow-private-networks`. تذهب رسائل التشخيص إلى stderr، ويُخصص stdout لرسائل البروتوكول فقط. يدعم الخادم إصدارات MCP المحددة في التنفيذ، ومنها `2026-07-28` وإصدارات سابقة متوافقة.

تشمل إعدادات الأمان الافتراضية حظر الشبكات الخاصة (بما فيها وجهات التحويل حيث تدعمها وسيلة النقل)، وحد جسم 5 MiB، واقتطاع النص الناتج، وقائمة مضيفين اختيارية، وعلامة `untrusted_content` في النتائج. قائمة المضيفين فارغة افتراضيًا، لذلك استخدم `--allow-host` للمجالات المعروفة التي ينبغي للخادم الوصول إليها فقط.

يعطل الخيار `--allow-private-networks` حظر الشبكات الخاصة في خادم MCP. لا تستخدمه مع مستدعي أدوات غير موثوقين؛ فهو ليس خيار توافق بسيطًا.

تحتوي نتائج MCP على محتوى بعيد. تعامل معه كبيانات غير موثوقة لا كتعليمات. لا تنفذ أوامر تلقائيًا ولا تتبع تعليمات مضمنة في الصفحة ولا تمنح المحتوى البعيد إمكانية الوصول إلى أسرار أو أدوات ذات صلاحيات.

## إرشادات نشر الأدوات

- شغّل عملية MCP بحساب نظام تشغيل محدود الصلاحيات.
- طبّق قواعد خروج شبكي بصورة مستقلة عن قائمة المضيفين.
- اجعل قائمة المضيفين ضيقة قدر الإمكان.
- لا تكشف خادم MCP عبر وسيط شبكي غير مصادق عليه.
- ضع حدودًا لحجم الطلب والإخراج والوقت وعدد العملاء المتزامنين في طبقة الاستضافة.
